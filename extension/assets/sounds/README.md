# Extension Audio Assets

This folder contains the sound effects for the Cloud Misconfiguration Security Extension.

## Required Sounds
To enable the premium audio feedback feature, you will need to add the following sound file to this folder:
- `detect.mp3`

This sound plays once when a cloud platform (AWS, Azure, GCP) is detected and monitoring auto-activates.

### Recommendations for `detect.mp3`:
- Keep it short (under 1 second).
- Use a subtle, professional "tech" sound (e.g., a soft chime or a low-pitch digital blip).
- Ensure the volume is normalized so it isn't jarring to the user.
